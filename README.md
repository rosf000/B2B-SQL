# 🚀 B2B AI-Native Data Engineer — 12 個月轉職計畫

> **「你的核心競爭力不是『我會 Python』，而是『我懂 B2B 商業問題，並能用 AI + 技術解決它』。」**

---

## 🎯 職涯定位

```
B2B Domain Knowledge
        +
SQL / Database / Python / ETL
        +
AI Agents / Automation
        =
B2B Data / Automation Engineer
```

**目標職稱：** Data Engineer ／ Data Automation Engineer ／ B2B Data Platform Engineer

**核心優勢：** 非本科轉職者的最強護城河 — B2B 商業背景 × 資料工程能力 × AI 工具驅動

## ⚡ AI-Native 學習原則

```
每個技術主題的學習循環：

自己先想 → 自己先寫 → AI 比較差異 → 理解為什麼 → 改進

不是：AI 生成 → 複製貼上 → 完成
```

**你的學習不是「背技術」，而是「能設計解決方案、能驗證 AI 產出、能對結果負責」。**
