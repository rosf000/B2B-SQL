## Week 3 — B2B 商業 SQL 題庫

**目標：** 用 SQL 真正解決 B2B 業務問題，不只是語法練習。

### 必做的 10 個 B2B 商業 SQL 問題

```sql
-- 1. 哪些客戶三個月內沒有下單？
-- 2. 哪個業務本季業績最高？和上季相比成長多少？
-- 3. 哪些產品的回購率最高？（買了超過 1 次的客戶比例）
-- 4. 找出有多個重複帳號的公司（email domain 相同但 ID 不同）
-- 5. 計算每個客戶的平均下單間隔天數
-- 6. 哪些客戶消費金額在過去 12 個月持續下降？
-- 7. 每個月的新客戶數 vs 回購客戶數
-- 8. 哪些業務的客戶流失率最高？
-- 9. 按產品類別分析各季度的銷售趨勢
-- 10. 找出「高價值但低活躍度」的客戶（消費高但近期沒動靜）
```

## 每天的 AI 協作方式

```
做 SQL 題的標準流程：

1. 讀題，自己想邏輯（2–5 分鐘）
2. 自己寫出 SQL（哪怕不完整）
3. 執行，看結果對不對
4. 如果卡住超過 15 分鐘，可以問 AI：
   「我的思路是 [說你的想法]，但我寫出來是 [貼你的 SQL]，哪裡有問題？」
5. 理解 AI 的解釋，自己重新敲一遍正確版本
6. 記錄「這道題學到什麼」
```

## Git Commit 規範（從 M1 開始養成）

```
格式：type: 簡短說明

類型：
feat:   新增功能 / 新完成的練習
fix:    修正錯誤的 SQL 或 code
docs:   README / 筆記 / 說明更新
refactor: 重構但不改變功能

範例：
feat: M1 Week2 JOIN 練習完成
fix: M1 SQL 題目 05 邏輯錯誤修正
docs: M1 Checkpoint 驗收完成
```
