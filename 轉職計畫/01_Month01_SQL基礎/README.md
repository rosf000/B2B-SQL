- [ ] 徹底理解 `NULL` 特性（`IS NULL` vs `= NULL` 的世紀大坑）。

## 🚀 學習建議與疑難排解

- **卡關時不要慌張**：遇到報錯時，先看錯誤訊息最後一行的提示（例如是不是拼錯欄位名稱？是不是漏了單引號？）。
- **善用 DBeaver 的自動補全**：打出前幾個字母後按鍵盤 `Ctrl + Space`，DBeaver 會自動提示資料表或欄位名稱。
- **隨時紀錄痛點**：將你寫 SQL 時遇到的盲區記錄在筆記本中，這將成為你未來面試時最有價值的「踩坑與解決問題的故事」。
