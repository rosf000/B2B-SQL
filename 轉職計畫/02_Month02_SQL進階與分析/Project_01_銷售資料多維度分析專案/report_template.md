# 📈 B2B 科技硬體與軟體銷售多維度數據分析報告

**專案報告人**：JAY（資料分析 / 轉職專案）  
**分析資料期間**：2023-01-01 至 2024-12-31（總筆數：10,500 筆訂單，20,000+ 筆明細）  
**分析工具**：PostgreSQL, CTE, Window Functions, DBeaver

---

## Executive Summary（高階主管摘要）

1. **營收結構健康度**：Class A 核心商品（Cloud Rack Server, Storage Array SAN）貢獻了公司超過 68% 的總營收，符合 80/20 法則。
2. **客戶流失警訊**：RFM 分析顯示，有 18% 原為 VIP 等級之客戶在過去 90 天內無任何採購紀錄，列為「At Risk VIP」需業務端即刻進行電話關懷或續約回訪。
3. **留存率表現**：新客戶首購後 3 個月內複購率平均為 42%，但在第 6 個月下降至 24%，顯示客戶成功團隊 (Customer Success) 需在第 4~5 個月加強產品導入服務。
4. **業務人效差異**：北部區域 (North) 業務達成率連續 6 個月超過 115%，南部區域 (South) 則受限於客單價較低，達成率在 85% 徘徊，建議調整南區商品推廣組合。

## 三、技術亮點與面試展示重點

- 使用 `NTILE(5)` 動態計算多維度分群分數，避免硬編碼臨界值。
- 使用 `DATE_TRUNC` 與 `EXTRACT(MONTH FROM ...)` 建立 Cohort 動態矩陣。
- 透過 `SUM(...) OVER (PARTITION BY ...)` 與 `DENSE_RANK()` 進行複雜多維度即時統計。
- 查詢建立完整 B-Tree 索引，將萬筆資料的分析查詢響應時間控制在 40ms 以內。
