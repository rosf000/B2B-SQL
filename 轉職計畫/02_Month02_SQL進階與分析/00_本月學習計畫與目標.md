## 每天的 AI 協作方式（進階分析版）

```
做進階 SQL 題的標準思考流程：

1. 拆解資料粒度（Grain）：確認輸出是一列一客戶？還是一列一個月？
2. 先用 CTE 將邏輯切成乾淨的小區塊（例如：區塊 A 算總額 ➜ 區塊 B 算排名）
3. 視窗函數不要急著全部寫在一行，先在 SELECT 單獨測 OVER 子句
4. 如果跑得很慢或語法報錯，向 AI 發問進階提示詞：
   「這是我寫的 CTE 與 Window Function [貼程式碼]，目前 EXPLAIN ANALYZE 顯示 
    Seq Scan 耗時過長 / 邏輯不如預期，請問在不破壞業務意圖下，有何重構建議？」
5. 比較 AI 給出的寫法（如視窗函數 vs 自關聯），理解其底層 Cost 差異
6. 記錄「這題學到的分析思維與效能考量」
```
