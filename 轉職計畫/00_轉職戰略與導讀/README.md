# 00 轉職戰略與導讀模組

> **「非本科轉職最大的陷阱是：忘記過去累積的商業價值，把自己當成剛畢業的資工系大一學生去跟本科生拼底層演算法。」**

本模組是整個 12 個月轉職旅程的「思想地圖」與「戰略指南」。在開始敲下第一行代碼之前，請務必精讀以下三大心法指引：

---

## 📑 模組篇章導航

1. [01_非本科B2B轉職優勢定位與策略.md](./01_非本科B2B轉職優勢定位與策略.md)
   - 分析為什麼「B2B 商業實務經驗 + 現代 IT 技能」是市場上的稀缺組合。
   - 釐清非本科轉職者的優勢戰場（Data Analyst, Analytics Engineer, Junior Backend / Data Engineer）。
   - 破解「沒資工學歷面試官看不上」的心態迷思。

2. [02_日常工作痛點轉化IT經驗手冊.md](./02_日常工作痛點轉化IT經驗手冊.md)

   - 提供「工作痛點轉 IT 專案觀察筆記範本」。

3. [03_年度學習方法論與排程範本.md](./03_年度學習方法論與排程範本.md)

   - 「不盲目抄 AI 代碼、先 Debug 30 分鐘」的刻意練習法。
   - Notion / Google Sheet 進度排程表模板。
