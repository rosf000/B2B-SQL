# 01 非本科 B2B 轉職優勢定位與策略

## 一、重新定義你的轉職人設

很多非本科轉職者在面試時容易陷入自卑：
> 「我沒有 CS 學位，資工系大一就在寫 C++、算離散數學，我怎麼跟他們競爭？」

**這是一個嚴重的定位錯誤。**

企業（特別是 B2B SaaS、科技業、金融科技、電商等）招聘初階工程師時，最常抱怨的不是「工程師不會寫 LeetCode Hard」，而是：
1. **聽不懂商業邏輯**：不知道為什麼訂單要有 status 流轉、不懂發票與出貨單的關聯、不理解業務部門為什麼需要這個指標。
2. **缺乏溝通能力**：只會埋頭寫代碼，遇到規格不明確時不會主動向業務端確認。
3. **不知道真實資料有多髒**：學校作業的資料都是乾淨的 CSV，真實企業資料充滿 NULL、拼錯字、重複統編與日期混亂。

如果你有 **B2B 業務 / 營運 / 專案經驗**，你天然擁有「懂業務場景」的巨大優勢。
當你再加上：
- **扎實的 SQL 查詢與分析能力**
- **資料庫架構設計思維（ER 模型、正規化）**
- **Python 自動化與資料管線開發能力**
- **FastAPI / Docker 後端與容器化實務**
- **LLM AI 應用落地的工程整合能力**

你呈現給面試官的形象就是：**「能夠用技術解決真實商業痛點的複合型人才」**。

## 三、避開三大轉職常見雷區

1. **雷區一：只看不練，陷入「教學影片地獄」(Tutorial Hell)**
   - 解決方案：本教材強制要求「每一模組必有實作程式碼與專案產出」，不只看語法，而是手打練習題並解決 Bug。

2. **雷區二：過度依賴 AI 複製貼上**
   - 遇到問題可以用 AI 詢問原理，但程式碼必須一行一行理解並自己手敲。
   - 遇到 Bug 請先強制自己除錯 15~30 分鐘，學會閱讀 Traceback 與錯誤訊息。

3. **雷區三：作品集全是罐頭專案（To-do App、鐵達尼號預測）**
   - 解決方案：本教材設計的 **B2B 客戶數據管理系統** 與 **AI Text-to-SQL 數據助理**，直接模擬企業級真實場景，讓面試官一眼看出你的實務價值。
