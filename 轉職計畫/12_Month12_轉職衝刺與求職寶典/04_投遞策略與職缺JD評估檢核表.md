# 04 投遞策略與職缺 JD 評估檢核表

## 一、破解 JD (Job Description) 的迷思

1. **「需具備 2-3 年相關工作經驗」**
   - **真相**：很多企業 HR 習慣套用固定模板。如果你的專案作品集（GitHub 四大專案 + Live Demo + 乾淨代碼）能證明你具備即戰力，就算工作年資未滿 2 年也請**大膽投遞**。
2. **「熟悉 10 種以上技術名詞」**
   - **真相**：企業通常只需要其中的 3-4 項核心技術（例如只要熟悉 Python + SQL + Docker 就能滿足 80% 工作內容）。

## 三、每週面試覆盤閉環 (Weekly Reflection)

每次面試結束後，於 2 小時內完成以下覆盤：
1. **被問倒的技術問題**：記錄具體問題，查閱官方文件並手寫 Demo 代碼驗證。
2. **專案介紹是否流暢**：是否有在 3 分鐘內講清楚「商業痛點 ➜ 技術選型 ➜ 成果指標」？
3. **主動提問 (Reverse Interviewing)**：是否有向主管詢問團隊技術架構與新人培養機制？
