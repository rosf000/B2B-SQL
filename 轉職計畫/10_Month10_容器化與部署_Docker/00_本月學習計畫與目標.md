## 每天的 AI 協作方式（雲端部署版）

```
雲端部署與維運時的 AI 協作心態：
「AI 往往會叫你直接把 .env 檔案複製進 Docker 映像檔，這是極其危險的資訊安全死穴！
 你的工程價值在於：理解容器與宿主機的環境邊界，並堅持『配置與程式碼嚴格分離』。」

標準協作步驟：
1. 遇到容器啟動失敗或網路不通時，先用 docker logs 獲取完整錯誤日誌
2. 將日誌與相關的 docker-compose.yml 貼給 AI，指示其進行診斷
3. 追問安全防禦細節：
   - 「在 Dockerfile 裡如何利用 --chown=appuser:appuser 確保權限安全？」
   - 「請幫我寫一個 smoke_test.sh，用 curl 檢查 HTTP 200 與回應 JSON 鍵值」
4. 在本機驗證通過後，再推送到 GitHub 觸發雲端平台構建
```
