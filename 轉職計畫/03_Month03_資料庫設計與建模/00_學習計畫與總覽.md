# 📅 Month 03 學習計畫與目標 — 資料庫設計與建模

> **從 M1/M2 的「查詢者」升級為「設計者」**
>
> M01 你學會了用 SQL 查詢 b2b_learning 資料庫。M02 你學會了用 Window Functions 和 CTE 做複雜分析。
> 但你有沒有想過：那個你一直用的 `customers`、`orders`、`order_items` 是誰設計的？為什麼不能把所有欄位都放在一張大表？
>
> M03 的核心任務就是：**你從「用別人設計的 schema 查資料」，升級為「自己設計企業級 schema」**。
> 而且你會發現，好的 schema 設計讓你 M02 的 Window Functions 查詢可以跑更快、結果更準確。

## 📝 Git Commit 規範

```
<type>: M3 Day<N> <簡短說明>
```

| Type | 使用時機 |
|------|---------|
| `docs` | 學習筆記、分析記錄、說明文件 |
| `feat` | 新增 SQL 實作、Schema、Trigger、View |
| `fix` | 修正之前的 SQL 錯誤或設計缺陷 |
| `refactor` | 重構既有 schema 或 SQL（不改功能） |
| `test` | 驗證腳本、效能測試、並發測試 |

**範例：**
```
docs: M3 Day1 分析 b2b_learning schema 設計意圖筆記
feat: M3 Day3 1NF 修正練習 — customer_phones 表重構
feat: M3 Day6 B2B ER Diagram Mermaid 繪製完成
feat: M3 Day13 FOR UPDATE 防超賣交易實作
feat: M3 Day24 Milestone 完整 DDL schema.sql 撰寫完成
docs: M3 Day28 Exit Exam 完成 — 解答與錯題筆記
```
