# A3｜職缺市場研究：從第一天起就追蹤市場

> 不要等到 M12 才開始看市場。從現在起，每週觀察職缺，讓學習方向跟著市場走。

## 用途

- 記錄台灣（或目標地區）的 Data Engineer / Automation 職缺要求
- 追蹤哪些技能高頻出現，調整學習優先順序
- 建立技能矩陣，對照自己的學習進度

## 資料夾結構

```
A3_職缺市場研究/
├── README.md
├── 01_目標職缺分析.md      ← 三條目標路線的技能需求
├── 02_技能矩陣.md          ← 自己 vs 市場的差距分析
└── job_tracker.csv        ← 投遞紀錄（M8 開始填寫）
```

## 更新頻率

- M1–M7：每月看一次職缺，更新技能矩陣
- M8 起：每週更新投遞紀錄
