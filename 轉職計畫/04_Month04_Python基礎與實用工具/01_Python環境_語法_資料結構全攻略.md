## 一、虛擬環境 (Virtual Environment) 的重要性

絕不要將第三方套件全局安裝在系統 Python 中。請在專案根目錄建立獨立虛擬環境：

```bash
# 1. 建立名為 .venv 的虛擬環境
python -m venv .venv

# 2. 啟動虛擬環境 (Windows PowerShell)
.\.venv\Scripts\Activate.ps1

# 3. 升級 pip
python -m pip install --upgrade pip
```

## 二、四大內建資料結構對比與操作

```text
┌──────────┬──────────┬──────────┬──────────────────────────────────────────┐
│ 資料結構 │ 符號/表示│ 順序性   │ 核心特徵與商業應用場景                   │
├──────────┼──────────┼──────────┼──────────────────────────────────────────┤
│ List     │ [1, 2, 3]│ 有序可變 │ 存儲序列資料，如 [訂單1, 訂單2, 訂單3]   │
├──────────┼──────────┼──────────┼──────────────────────────────────────────┤
│ Dict     │ {"k": "v"}│ 鍵值映射 │ 存儲實體屬性，如 {"tax_id": "28491023"}  │
├──────────┼──────────┼──────────┼──────────────────────────────────────────┤
│ Set      │ {1, 2, 3}│ 無序唯一 │ 快速去重或集合運算 (如找出交集客戶名單)   │
├──────────┼──────────┼──────────┼──────────────────────────────────────────┤
│ Tuple    │ (1, 2)   │ 有序不可變│ 存儲不可篡改的常數或資料庫單筆查詢結果   │
└──────────┴──────────┴──────────┴──────────────────────────────────────────┘
```

## 三、常用高級語法：推導式 (Comprehensions)

```python
# 1. List Comprehension: 篩選出大於 10 萬的訂單金額並轉為含稅價 (x 1.05)
raw_amounts = [50000, 120000, 350000, 80000, 200000]
tax_included_large_orders = [int(amt * 1.05) for amt in raw_amounts if amt >= 100000]
# 結果: [126000, 367500, 210000]

# 2. Dict Comprehension: 建立「統編 -> 客戶名稱」的快速查找字典
customers = [
    {"tax_id": "28491023", "name": "Apex Semi"},
    {"tax_id": "54329871", "name": "BlueSky Cloud"}
]
tax_lookup = {c["tax_id"]: c["name"] for c in customers}
# 結果: {'28491023': 'Apex Semi', '54329871': 'BlueSky Cloud'}
```
