## 一、函式設計與類型標註 (Type Hints)

現代 Python 開發（特別是配合 FastAPI 或大型資料管線時）強烈推薦使用 **Type Hints**，能大幅提升代碼可讀性與 IDE 自動補齊：

```python
from typing import List, Dict, Optional

def calculate_discounted_total(
    unit_price: float, 
    quantity: int, 
    discount_rate: float = 0.0,
    tax_rate: Optional[float] = 0.05
) -> Dict[str, float]:
    """計算折扣與稅後金額。"""
    if quantity <= 0:
        raise ValueError("數量必須大於 0")
    
    subtotal = unit_price * quantity
    discount_amount = subtotal * discount_rate
    net_amount = subtotal - discount_amount
    tax = net_amount * (tax_rate if tax_rate is not None else 0.0)
    total = net_amount + tax
    
    return {
        "subtotal": round(subtotal, 2),
        "discount": round(discount_amount, 2),
        "tax": round(tax, 2),
        "final_total": round(total, 2)
    }
```

## 二、防禦性程式設計：例外處理 (Exception Handling)

```python
import logging

logging.basicConfig(level=logging.INFO, format="%(asctime)s [%(levelname)s] %(message)s")

def parse_order_amount(raw_str: str) -> Optional[float]:
    """將文字金額安全轉為 float，若格式錯誤則優雅處理不崩潰。"""
    try:
        clean_str = raw_str.replace("$", "").replace(",", "").strip()
        amount = float(clean_str)
        if amount < 0:
            raise ValueError(f"金額不可為負數: {amount}")
        return amount
    except ValueError as e:
        logging.warning(f"解析金額失敗: '{raw_str}' -> {e}")
        return None
    except Exception as e:
        logging.error(f"非預期錯誤: {e}", exc_info=True)
        return None
```
