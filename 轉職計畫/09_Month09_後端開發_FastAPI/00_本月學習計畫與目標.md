> **「只會把數據存在資料庫裡叫離線數據；能把數據封裝成現代 RESTful API 給前端、手機 App 或 AI Agent 呼叫，才是全棧現代資料工程師。」**

## 每天的 AI 協作方式（後端 API 版）

```
開發 Web API 的 AI 協作原則：
「AI 寫出來的 API 常常忘記做分頁 (Pagination)、漏掉輸入驗證、或是把資料庫連線直接開在全域。
 你的工程價值在於要求 AI 遵循生產級契約（Contract First）與強型別驗證。」

標準協作步驟：
1. 自己先定義好 Pydantic Schema（Request 與 Response）
2. 把 Schema 餵給 AI，指示 AI 撰寫對應的路由函式
3. 嚴格審查 AI 程式碼：
   - 「是否使用 Depends(get_db) 注入 Session？」
   - 「查詢多筆時是否有 limit 和 offset 分頁控制？」
   - 「找不到資源時是否有明確拋出 status_code=404？」
4. 讓 AI 為該端點自動生成 2 組 TestClient 測試程式碼（1 組成功、1 組異常）
```
