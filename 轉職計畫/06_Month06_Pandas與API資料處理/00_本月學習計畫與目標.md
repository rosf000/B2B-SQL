## 每天的 AI 協作方式（API 與數據處理版）

```
串接 API 與 Pandas 處理時的 AI 協作標準心態：
「AI 寫出來的 API 腳本通常假設網路永遠良好、API 永遠不變、資料永遠完整。
 你的工程價值在於：迫使 AI 考慮網路中斷、超時、限流與惡意髒資料。」

標準協作步驟：
1. 先看目標 API 官方文件，把範例 JSON Payload 餵給 AI
2. 讓 AI 生成基礎提取與 DataFrame 轉換程式碼
3. 指示 AI 加上韌性防護：
   - 「請加上 timeout 參數與 requests.exceptions.RequestException 捕獲」
   - 「遇到 HTTP 429 時，請依照 Retry-After 標頭實作指數退避重試」
   - 「請將此程式碼改寫為使用 pd.json_normalize() 扁平化巢狀結構」
4. 在本地故意拔除網路或設定極短 timeout 進行破壞性壓力驗證
```
