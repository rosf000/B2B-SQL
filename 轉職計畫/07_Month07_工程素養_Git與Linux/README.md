# Month 07｜工程素養：Git 版本控制、Linux 伺服器與專業開源習慣

> **本月核心目標**：告別把代碼只塞在本機電腦或隨身碟的業餘習慣，像真正的軟體工程師一樣使用 Git 分支管理、Linux 命令列排錯，並打造專業高質感的 GitHub 個人作品集主頁。

---

## 🎯 本月技能檢核清單

- [ ] 掌握 Git 核心三區域：工作區 (Working Dir)、暫存區 (Staging)、版本庫 (Repository)
- [ ] 掌握分支操作：`git branch`, `git checkout -b`, `git merge`, `git rebase`
- [ ] 掌握遠端同步：`git remote`, `git push`, `git pull`, `git fetch`
- [ ] 規範化 Commit Message 寫法（Conventional Commits: `feat:`, `fix:`, `docs:`, `refactor:`）
- [ ] 編寫標準 `.gitignore` 檔案（防止上傳 `.env` 密碼金鑰與 `__pycache__`）
- [ ] 熟練 Linux 檔案與文字處理指令：`cd`, `ls`, `grep`, `cat`, `chmod`, `curl`, `top`, `ps`
- [ ] 掌握 SSH 金鑰配置與遠端伺服器連線
- [ ] 將前 6 個月的所有專案依照專業模板整理並開源至個人 GitHub
