## 每天的 AI 協作方式（DevOps 與環境配置版）

```
DevOps 與 Docker 配置時的 AI 協作原則：
「AI 生成的 Dockerfile 經常充滿安全漏洞（如以 root 身分執行、映像檔體積高達 1.5GB、
 或是把資料庫密碼寫死在代碼中）。你的工程價值在於要求 AI 遵守生產級最小權限與安全規範。」

標準協作步驟：
1. 讓 AI 生成初版 Dockerfile 或 docker-compose.yml
2. 指示 AI 進行安全審查與優化：
   - 「請將 Base Image 改用 python:3.11-slim 輕量化映像檔」
   - 「請將敏感資訊改由 .env 環境變數傳入，不可出現在 compose 檔案中」
   - 「請為資料庫服務加上 healthcheck 健康檢查設定」
3. 本地執行 `docker compose up` 驗證，並使用 `docker images` 檢查體積
```
