## 每天的 AI 協作方式（AI 系統架構師版）

```
開發 AI 應用時的 AI 協作原則：
「不要問 AI『你覺得這段 SQL 安全嗎？』AI 永遠高估自己的安全性。
 必須以『零信任架構 (Zero Trust)』設計系統，假設所有 LLM 輸出的代碼都帶有潛在危害。」

標準協作步驟：
1. 讓 AI 生成特定功能的原型代碼（例如 sqlparse 語法分析）
2. 要求 AI 站在黑客視角扮演攻擊者：
   - 「請寫出 5 種能繞過這段正則表達式的 SQL 注入變形」
   - 「請指出這段 Function Calling 在並發執行時可能造成的安全漏洞」
3. 採用程式碼（代碼級硬約束）來防禦 AI，而不是靠自然語言提示詞祈禱 AI 聽話
4. 本地運行所有滲透測試用例，確認攔截率達 100%
```
