# 🎯 全教材教學架構優化實施計畫（六步認知循環與主動回想重構）

> **架構核心哲學**：
> 
> ① 先說這一段最重要的事（核心心智模型定位）
> ↓
> ② 告訴學生為什麼重要（商業痛點、工作場景、生產事故代價）
> ↓
> ③ 解釋底層原理（運作機制、資料流向、為什麼這樣設計）
> ↓
> ④ 給出對比例子（好壞代碼對比、可復現商業範例）
> ↓
> ⑤ 讓學生自己做（情境提問、白紙空白頁挑戰、折疊式防暴雷答案）
> ↓
> ⑥ 最後再次收斂成一句話（記憶錨點、核心公式、避坑口訣）
>
> 濃縮為四部曲：**「先定位 ➔ 再理解 ➔ 再操作 ➔ 再回收」**。
> **核心原則**：「結論先行」是傳遞核心心智模型，而非提前劇透答案；必須深度整合「情境提問」、「間隔練習（Spaced Repetition）」與「主動回想（Active Recall）」。

## 💡 核心教學法規範：認知科學三支柱

為了徹底落實「先定位 ➔ 再理解 ➔ 再操作 ➔ 再回收」，本優化方案確立三大認知科學工程標準：

### 支柱一：心智模型定位先行（Conclusion & Mental Model First）
- **錯誤做法**：在頁面開頭直接給出 SQL 或 Python 答案。這會剝奪學生的解題探索欲望。
- **正確做法**：在章節開頭用**一句話點破技術本質（心智模型）**，並用**一個具體痛點引發學習飢餓感**。
  - *範例*：「視窗函數（Window Function）的本質，是在不壓扁原始資料列的情況下，讓每筆資料都能『轉頭偷看』群體統計值。」

### 支柱二：強迫主動回想與防暴雷折疊（Active Recall by Forced Folding）
- 所有教材內部的小節動手做、章節綜合題、Exit Exam 與 M12 面試題，**嚴禁將解答直接印在題目下方**！
- 統一採用 HTML `<details><summary>` 標籤進行雙層防護：
  1. **第一層思考引導（Hints）**：提示邏輯步驟、使用的關鍵字或拆解思路。
  2. **第二層參考解答與解析（Solution & Deep Dive）**：包含標準代碼、面試擬答、易犯錯誤分析與「為什麼這樣寫」。
- 學生必須先在紙上或編輯器內寫出初步答案，才能點開對照。

### 支柱三：間隔練習與螺旋複習鉤子（Spaced Repetition & Spiral Retrieval Hooks）
- 技能不是學完就忘，在每個月教材的開頭，設置 **「🧠 5分鐘間隔回想暖身（Retrieval Hook）」**：
  - 例如 M05（Python x DB）開頭回想 M01 的 SQL Connection 與 Transaction 原理；
  - M09（FastAPI）開頭回想 M06 的 Pydantic / 字典結構驗證；
  - M10（Docker）開頭回想 M07 的 Linux 指令與行程概念。

## 🛠️ 教材標準改裝組件規範（6 步標準結構）

未來所有改版檔案，各核心章節必須遵循統一的 Markdown 結構組件：

### 1. 章節入口：①定位句 ＋ ②痛點場景（先定位）
```markdown
### 關卡 X：[主題名稱]

> 🎯 **這一節最重要的一件事（心智模型）**：
> [一句話直指技術本質，建立大腦直覺模型]
>
> 💼 **為什麼你非學不可（商業場景與避坑代價）**：
> [若不懂此技術，在實際公司會面臨什麼痛點、客訴、或面試翻車事故]
```

### 2. 中段原理解構：③原理機制 ＋ ④對比示範（再理解）
```markdown
#### 1. 底層原理與運作機制（Mental Model）
[透過圖解、ASCII 表格或簡潔比喻解釋運作邏輯]

#### 2. 實戰示範：反例（踩坑） vs 正例（推薦）
- ❌ **常見危險寫法**（直覺但有缺陷）：
```sql/python
-- 代碼範例
```
- ✅ **生產級正確寫法**（強健且具備可維護性）：
```sql/python
-- 代碼範例
```
```

### 3. 動手刻意練習：⑤自主操作 ＋ 主動回想（再操作）
```markdown
#### 3. ✋ 刻意練習：空白頁挑戰（不看上方範例）
> **主管突發需求**：
> 「[具體商業問題描述]」
> 
> ⚠️ **請立刻打開你的編輯器/終端機，在空白頁自己寫出解答，切勿直接偷看下方折疊！**

<details>
<summary>💡 需要思考提示嗎？（點擊展開提示思路）</summary>

1. 第一步：先確認資料來源表與需要的過濾條件...
2. 第二步：判斷是否需要聚合或開窗...
3. 關鍵關鍵字：`...`
</details>

<details>
<summary>✅ 寫完了？點擊對照標準解答與思維解析</summary>

```sql/python
-- 標準生產級代碼
```
**關鍵眉角解析**：
- 為什麼不能用 A 寫法：...
- 面試官最看重的細節：...
</details>
```

### 4. 章節出口：⑥核心收斂 ＋ 回想錨點（再回收）
```markdown
> 💡 **這一關的核心收斂（記憶錨點）**：
> **「[朗朗上口的核心公式 / 避坑金句 / 決策樹簡化原則]」**
```
